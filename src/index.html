HOW THE BOOKING SYSTEM WORKS

From voice conversation to confirmed booking

1. Ask Ava

The caller asks about lessons, programs, pricing, or available lesson times.

2. Check Availability

Ava checks the live booking database and offers only the lesson slots that are currently available.

3. Confirm Details

Ava collects the customer's name, callback number, service, date, and selected lesson time.

4. Create Booking

After customer confirmation, Ava creates the booking and stores it securely in the booking database.
